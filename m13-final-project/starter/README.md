**Транзакції.** <!-- Де починається і закінчується транзакція переказу та імпорту -->

**Блокування.** <!-- Чому pessimistic lock для переказів, чому в порядку id, навіщо ще й @Version -->

**DTO замість entity.** <!-- Що зламалося б, якби віддавати Account у JSON -->
