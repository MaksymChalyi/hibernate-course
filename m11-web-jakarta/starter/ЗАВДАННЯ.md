# Модуль 11 — завдання

Теорія — у лекції «Модуль 11 — Hibernate у веб-застосунку на Jakarta». Список місць у коді: **View → Tool Windows → TODO**.

Mini Bank стає REST API на вбудованому Tomcat. Сервіси (`AccountService`, `TransferService`) уже готові — треба зібрати застосунок і написати servlet-и.

## Обов'язкова частина

| № | Файл | Що зробити |
|---|---|---|
| 1 | `web/AppContextListener` | При старті: Flyway → `EntityManagerFactory` → сервіси → `AppContext` у `ServletContext` |
| 2 | `web/AppContextListener` | При зупинці: закрити `EntityManagerFactory` |
| 3 | `web/AccountServlet` | `GET /accounts/{id}` → `AccountDto` або 404 |
| 4 | `web/TransferServlet` | `POST /transfers` → переказ |

Перевірка після 1–2: запусти `Main` — у консолі `Mini Bank API: http://localhost:8080/accounts/1` без помилок.
Після 3: відкрий http://localhost:8080/accounts/1 у браузері (перезапусти `Main`).
Після 4: тести `WebApiTest` «1–3 …» і «4 …» зелені.
